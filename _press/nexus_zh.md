# 家族卫队 · 座舰改装（Dynasty Retinue & Refit）

**一支替你打仗的私人护卫队，和一艘真能改装的座舰。**

---

## 这个 mod 做什么

行商浪人执掌的是一个**家族**。身边只跟五个同伴就下场火并，怎么想都不对劲。

这个 mod 给你一支**私人卫队**——由 AI 操控的士兵，加入你的队伍，沿着真实的职业链成长，
穿真实的装备，自己打完整场战斗。同时让你**改装座舰**：护卫舰 → 巡洋舰 → 大巡洋舰，
而且**船体外观真的会变**。

所有内容都用**原版蓝图**搭成。没有自造单位、没有自造 AI、没有凭空发明的物品。

---

## 卫队

**五个分型，每个三档职业。**

| 分型 | 定位 |
|---|---|
| 近战 | 压上去，顶住正面 |
| 狙击 | 标记目标，远距离收割 |
| 连射 | 重型伐木枪 / 自动炮 / 重爆矢枪，持续压制 |
| 灵能 | 亚空间能力，处决 |
| 军官 | 增益、指挥，让队伍转起来 |

卫兵**跟着你升级**（默认拿你 80% 的经验，另有可选的追赶曲线，让后招的兵不至于是累赘），
走**真正的 Owlcat 职业路径**，并**按档位自动配装**——包括植入物，会随你剧情解锁的植入层级一起升级。

**十名精英。** 每条线两个，需要该线先练出一名三档卫兵才解锁。它们都由原版具名单位改成——
法务部小队长、战斗修女、审判庭秘能者——各有自己的位阶：
*铁壁卫长*、*寂静之眼*、*怒火铳长*、*圣焰净罪*、*亚空间审判者*、*铁律政委*……

**它们会死。** 普通卫兵永久死亡，精英有倒地豁免。招募名额由**利润因子**决定，
卫队随家族一起壮大。

**镜头不会乱跳。** 每回合多五个单位行动，镜头一个个跟过去会让人晕。默认它不跟——
你想看哪就看哪。（可关）

## 座舰

用废料改装。**船体模型真的会换**——十一个原版船模可选，从 Sword 级护卫舰到混沌战列巡洋舰。

| | 巡洋舰 2×4 | 大巡洋舰 3×6 |
|---|---|---|
| 护盾上限 | +50% | +100% |
| 装甲（减伤） | +50% | +100% |
| 撞角额外行程 | 速度 × 100% | 速度 × 200% |
| 武器射程 | +3 | 舷炮 +3 / 舰首 +5 |
| 每回合开火次数 | 舷炮 +1 | 舷炮 +2 / 舰首 +1 |

以上都是面板里的滑条，随你调。改装**可退款**——还原时按同样的规则退回废料。

**顺手修了个原版 bug：** 原版的舰船管理界面四个方向的装甲值都读 `ArmourFore`。
这个 mod 接管了那处显示，改成从伤害计算的同一个源头取真实的各面数值。

## 需求

- **Unity Mod Manager 0.23.0 以上**
- **不强制要求任何 DLC。** 五个分型里有四个的单位模板来自 **DLC3（Dark Legacy）**，
  没有的话会自动退到本体模板：职业链、装备、AI、成长全部照常，只是外观和自带能力
  会变成对应精英的样子。真发生回落时面板上会显示一行提示。
- 一名精英（圣焰·净罪修女）和一条二档职业链（火杖行刑者，DLC1）在缺对应 DLC 时不可用。

## 安装

> **从 1.0 之前的版本升级？** 旧版文件夹叫 `KgdRetinue`。
> 解压新版**只会多出一个** `DynastyRetinue` 文件夹，不会覆盖旧的——因为 UMM 是按
> 「子目录里有没有 Info.json」装载的，不认目录名。
> 请把旧文件夹**删掉或移出** UnityModManager 目录，**只改名没用**。
> 存档里的卫兵不受影响。

1. 装 Unity Mod Manager（0.23.0 或更高）
2. 把压缩包解压到你的 UnityModManager 目录
3. 启动游戏，`Ctrl+F10` 打开 UMM 面板，找到 **Dynasty Retinue & Refit**
4. 读一个存档——大部分功能需要在游戏里才可用

## ⚠️ 卸载之前

卫兵是**持久实体**，会写进存档的 `party.json`，改装过的座舰也是。
关掉 mod 不会让它们消失，而是把它们**留在存档里、同时拿走处理它们的代码**。

**两分钟的清理：**

1. UMM 面板 → 顶部 → 点【**遣散全部**】，确认日志出现「复查在册 0，清理完成」
2. 如果改装过座舰：**舰船**区 → 点【**还原原版船模**】
3. **存盘**
4. 然后才能关 mod

第 3 步很关键——前两步只发生在内存里。

### 不这么做会怎样 —— 三条路径都实测过

| | 存档能开 | 后果 | 能不能修 |
|---|---|---|---|
| 按流程清理后卸载 | ✅ | 无残留 | — |
| 不清理直接卸载 | ✅ **也能开** | 卫兵变成不可操作的静止 NPC；改装过的座舰在管理界面显示为**一片洋红** | ⚠️ 卸载状态下没有办法，但装回 mod 就能完全修好 |
| 卸载错了再补救 | ✅ | **可以完全恢复** | ✅ 装回 mod → 遣散 + 还原 → 存盘 |

**存档在任何路径下都不会损坏。** 这个 mod 写进存档的一律是裸字符串或原版枚举，
从来没有 mod 自造的蓝图进过类型化字段——而那才是真正会让行商浪人存档打不开的东西。

跳过清理会留下一个**在 mod 不在时收拾不了**的烂摊子，但它完全可逆：
装回来、正常清理、再卸载。

## 兼容性

与 **ToyBox** 和 **RTAutoBuilder** 一起实测过。所有 Harmony 补丁都以
「这是不是我的卫兵」为前置，任何异常都会交还原版流程。

装了 RTAutoBuilder 的话，它的加点方案会被自动识别成额外的成长模板。

## 完整特性清单

**卫队本身**

- 五个分型 × 三档职业，走真实的原版职业路径
- 十名精英，每条线两个，需该线练出三档卫兵才解锁
- **普通卫兵永久死亡**；精英有倒地豁免（0 血进入昏迷而非死亡）
- 招募名额由**利润因子**决定，面板上有分级表告诉你下一档还差多少
- 经验跟随主角（默认 80%），可选**追赶曲线**：落后越多补得越快，但永远不会反超你
- 按档位**自动配装**，含植入物；植入物会随剧情解锁的层级自动升级
- 装备表是 JSON，**你可以自己改**（`archetypes.json`），配了不存在的物品会静默跳过

**打起来的时候**

- **镜头不会跟着卫兵跑** —— 每回合多五个单位行动，镜头一个个跟过去会让人晕。
  默认不跟随，你想看哪就看哪；你自己队伍的运镜不受影响。可关
- 卫兵有**独立的士气池**，不占用你队伍那条
- 击杀正确归属到卫兵，队伍士气该加的加
- 卫兵阵亡**不会**按「击杀队友」给敌方加士气（原版会）
- 卫兵的行动**不累积亚空间帷幕**——五个 AI 单位每回合乱放技能，
  按原版规则算会让帷幕迅速失控
- 卫兵的自带装备**不会被系统倒进玩家仓库**

**座舰**

- 十一个原版船模可换，外观真的变
- 六项加成（护盾 / 装甲 / 射程 / 撞角 / 每回合开火次数），全部有滑条可调
- 改装**可退款**，按同样规则退回废料
- **自动补上缺失的武器挂点** —— 有些船模没有舰首槽位，不补的话光矛和鱼雷会
  「在虚空里开火」（美术挂不上，从原点发射）
- **挂点争用仲裁** —— 两件同类武器抢同一个槽位时，原版是先毁后建、谁赢取决于
  遍历顺序，玩家控制不了。这里按 光矛 > 新星炮 > 宏炮 > 鱼雷 定序，让舰首稳定显示光矛
- 修了原版舰船管理界面「四个方向的装甲值都读 ArmourFore」的抄漏

**使用体验**

- 三个招募入口：点击 NPC、NPC 对话里的选项、面板直接开窗，都可以单独关
- 中英双语，跟随游戏语言，也能在面板里手动切、不用重启
- **一键导出诊断包**：版本、你改过的设置、在册情况、舰船状态、日志尾部打包成一个文件，
  用户名已抹掉。报 bug 时比直接发日志小得多也全得多
- 危险操作（遣散全部、还原船模）需要**点两次**确认
