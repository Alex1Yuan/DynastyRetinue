# 配音稿（TTS 用）

**给剪映「文本朗读」用的中文女声稿。** 每一段单独一条，方便对轴。

## 使用方法

1. 剪映 → 文本 → 新建文本 → 贴入下面某一段
2. 右侧「朗读」标签 → 选音色 → 生成
3. 生成后把文本图层的透明度调到 0（只要声音，字幕另配）

## 音色建议

优先试 **「知性女声」/「解说小佳」/「温柔淑女」** 这类偏平稳的。
避开「甜美」「元气」——40K 的调性不合。语速用默认或 **0.9×**，
这稿子信息密度偏高，太快听不清。

## 写这稿时避开的坑

- **只避开会读错的英文**：`ArmourFore`、`Harmony`、`JSON` 这类换成中文说法；
  但 **`mod`、`AI` 这种中文玩家本来就直接讲的词要保留** —— 翻成「模组」「人工智能」反而生硬
- **不写符号**：`→`、`×`、`+50%` 会被跳过或读成怪音，改成"变成""倍""提升百分之五十"
- **短句**：TTS 断句靠标点，长句会一口气念完，听着喘不过气
- **数字用中文**：「三档」不写「3 档」，避免读成"三档"以外的东西
- **专有名词保持一致**：全片统一说"卫兵"不混用"守卫""护卫"

```
普通卫兵是永久死亡，没有读档以外的补救。只有精英有倒地豁免，血量归零时进入昏迷，而不是直接阵亡。
```

```
用废料把护卫舰改成巡洋舰，或者大巡洋舰。

```

```
卫兵和改装过的座舰都会写进存档，所以卸载之前要先遣散、还原、存盘。面板上两个按钮的事。

不这么做会怎样？我测过。存档不会坏，但卫兵会变成删不掉的雕像，船会变成这样一片洋红。

好消息是这可以救。把 mod 装回来，正常清理一遍就干净了。

源码开源，链接在简介里。
```

## 生成命令（要改词重跑用）

```bash
py -m edge_tts -v zh-CN-XiaoxiaoNeural --rate=-8% \
   -t "文本" --write-media 输出.mp3 --write-subtitles 输出.srt
```

`--rate` 必须用等号形式（`--rate=-8%`），
写成 `--rate -8%` 会被 argparse 当成选项名，报 usage 错误。

其它可选中文女声：`zh-CN-XiaoyiNeural`（活泼）、
`zh-CN-liaoning-XiaobeiNeural`（东北）、`zh-CN-shaanxi-XiaoniNeural`（陕西）。
后两个是方言，这个片子不合适。
