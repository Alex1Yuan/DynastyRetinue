# DynastyRetinue · 家族卫队

给《Warhammer 40,000: Rogue Trader》加一支**由 AI 操控的私人护卫队**，以及一套**座舰改装**系统。

用原版单位模板生成卫兵、按原版职业链自动成长、自动发装备，跟着你打完整场战斗。座舰那边可以用废料把护卫舰改装成巡洋舰或大巡洋舰，拿到对应的护盾、装甲、撞角与开火次数加成。

---

## ⚠️ 先读这一段：卸载之前必须做两件事

**卫兵是持久实体，会写进存档的 `party.json`。** 它们不是临时召唤物 —— 关掉 mod 并不会让它们消失，只会让存档里留下一堆读不出来的引用。

在**禁用 mod / 卸载 mod / 在 Steam 里关闭 DLC / 更换 Steam 账号**之前：

1. 打开 UMM 面板 → **面板顶部**（「卫队 在册 N」那一行下面）→ 点【**遣散全部**】，确认日志出现「复查在册 0，清理完成」
2. 如果换过船模：**舰船** 区 → 点【**还原原版船模**】
3. **存盘**
4. 然后才能关 mod

顺序不能反 —— 第 3 步之前的操作只在内存里，不存盘等于没做。

> **为什么要求这么严**：这条流程是**实测验证过**的。而"不清理就直接删 mod"那条路，理论上也安全（设计时一直按这个约束办），但**没有做过完整实验**，所以不给承诺。展开下面一节看具体验证到了什么程度。

<details>
<summary>为什么必须这么做，以及"不这么做会怎样"到底验证到什么程度</summary>

**设计上的规避**：所有写进存档的东西都只用**裸字符串**或**原版枚举** —— `PartCombatGroup.m_Id`、`PartUnitDescription.CustomName`、`m_CustomPrefabGuid`、`PartUnitState.Size`。全程没有任何 mod 自建蓝图被记进类型化字段。而"卸载后存档打不开"这个最严重的故障，恰恰只由后者引起（那类字段的反序列化处没有 try/catch，解析不到就整个存档读不出来）。

**已经实测验证的**（自动化测试端到端跑过）：

- 按流程走 —— 遣散全部之后复查在册 0、还原船模之后座舰回到原生档且自定义 prefab 已清空。这条是可靠的。

**只有设计保证、没有实验证据的**：

- ⚠️ **不按流程、直接删掉 mod 之后存档还能不能打开** —— 理论上可以（理由见上），写代码时一直按这个约束办，也做过基础验证，但**没有做过"故意不清理然后卸载再读档"的完整实验**。所以这里不敢给承诺。

因此：**请按上面的流程卸载**。那条流程是验证过的；绕过它的路径没有。

另外两点即使按流程也要知道：

- 卫兵实体在 `party.json` 里，它们引用的原版单位模板如果来自你后来关掉的 DLC，就会解析不到 —— 遣散是把这些实体真正销毁，而不是藏起来。
- 换过的船模：`m_CustomPrefabGuid` 是个原版 GUID 字符串，即使卸载 mod 存档也能开，但**外观会永久保持改装后的样子**，因为没有东西再去还原它。

## 安装

> **从 0.8x 版升级的话，先做这一步**：旧版的文件夹名是 `KgdRetinue`。
> 新版叫 `DynastyRetinue`，**解压新版只会多出一个文件夹，不会覆盖旧的** ——
> UMM 是按「子目录里有没有 `Info.json`」装载的，不认目录名。
> 两份同时跑 = 两套 Harmony 补丁、两个面板、两份名册认领同一批卫兵。
> 所以请把旧的 `KgdRetinue` 文件夹**整个删掉或移出 UnityModManager 目录**，
> 只改名是没用的。（存档里的卫兵不受影响，身份标记跨版本保持不变。）

1. 装 [Unity Mod Manager](https://www.nexusmods.com/site/mods/21) **0.23.0 或更高**，用它安装本 mod
2. 启动游戏，`Ctrl + F10` 打开 UMM 面板，找到 **Dynasty Retinue & Refit**
3. 读一个存档（不在存档里时大部分功能不可用，这是正常的）

`archetypes.json`、`plans.json`、`l10n_en.json` **三个都必须和 DLL 放在一起**。
前两个缺失时 mod 会退回内置默认值并在日志里报错，功能大幅退化；
`l10n_en.json` 缺失是**静默**回落中文 —— 英文玩家的表现是「这 mod 没做英文」，最难自查。

### 关于 DLC

本 mod **不强制要求任何 DLC**，但五个分型里有四个的单位模板来自 **DLC3（Dark Legacy）**。
没有 DLC3 时会自动退到本体单位蓝图：**职业链、装备、AI、成长全部照常**，
只是那几个分型的卫兵外观和自带能力会和对应精英相同。面板上会显示一行提示。
个别精英（圣焰·净罪修女）和一条 T2 职业链（火杖行刑者，DLC1）在缺对应 DLC 时不可用。

## 快速上手

**招募**：UMM 面板 → 招募 → 选分型 → 【直接开窗】。或者打开「在 NPC 对话里加选项」，之后跟**高阶顾问**（舰桥）对话，会多出一条「（护卫队）关于我的护卫队……」。

**招募上限**由**利润因子**决定：默认每 15 点解锁 1 名，最多 6 名（90 点全解锁）。招募窗口顶部会显示当前进度。

**换船**：跟高阶顾问对话选「（船坞）关于座舰的改装事宜……」，用废料购买：

| 目标 | 费用 |
|---|---|
| 护卫舰 → 巡洋舰 | 500 废料 |
| 护卫舰 → 大巡洋舰 | 1000 废料 |
| 巡洋舰 → 大巡洋舰 | **500**（只补差价） |
| 降级 / 还原 | **退还差价** |

## 功能

### 卫队

- **5 条分型**（近战 / 连射 / 狙击 / 灵能 / 军官）× **3 个阶位**，跟着主角等级解锁
- **10 名精英**，每条线 2 名，走各自的职业链和装备表
- **自动成长**：每次进区域按当前阶位补齐等级、加点、发装备
- **经验追赶**：等级落后主角越多，获得的经验倍率越高（最低 0.8×，可配置）
- **命名**：`军衔·人名`。晋升只换军衔，人名跟他一辈子；死了这个人就没了
- **死亡规则**：普通卫兵**永久死亡**，精英**倒地可救**
- **士气隔离**：卫兵受伤/倒地不扣你的队伍士气；可选独立士气池
- **镜头**：卫兵行动时可以不跟随，省掉大量等待

### 舰船

- 分档加成：护盾扇区上限、各面装甲、撞角距离、每回合开火次数
- 换船模（目前**只有帝国 Gothic 级巡洋舰和 Dictator 级大巡洋舰经过校准**，其余船体在船坞里会标注「未调整好」并禁止购买）
- 自动补齐缺失的武器挂点，修复原版「光矛在虚空里开火」的问题

---

## 已知限制

- **只有两条船体校准过**。目录里其余船体（混沌、灵族、运输舰）可以在 UMM 面板里强行切换用于尝试，但挂点位置和缩放没有验证过。船坞窗口不会卖给玩家。
- **同一挂点只能显示一件武器美术**。这是原版行为（`StarshipView` 是先毁后建），两件要求同一槽位的武器只有一件可见。本 mod 会优先保留光矛。
- **部分武器没有炮塔美术**（鱼雷发射管等），这是原版数据如此，不是缺陷。
- 精英模板中有一个来自 **DLC3**，没有该 DLC 时那名精英不可用。
- 【改装备】按钮属于第二阶段功能，目前点击只会提示"尚未实现"，卫兵使用固定装备组。

## 兼容性

- 与 **ToyBox** 兼容（设计时的硬约束之一）
- 不创建任何自定义蓝图，不给卫兵自定义 AI
- 所有持久化数据都是裸字符串或原版枚举

## 出问题时

日志在 `%USERPROFILE%\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\UnityModManager\DynastyRetinue\dynasty_log.txt`。

反馈时请带上这个文件 —— 里面记录了每一步的判据和数值，绝大多数问题能直接从日志定位，不需要来回猜。

**最省事的反馈方式**：UMM 面板上点【**导出诊断包**】。它会把版本、你改过的设置、在册卫兵、舰船状态和日志尾部打包成**一个文件**，并且**已经把用户名抹成 `<USER>`**。比直接发完整日志小得多，信息也全得多 —— 完整日志通常有好几 MB，多数地方传不上去。

（面板上没有「开发 · 测试」区是正常的：那些按钮会清空卫兵、输出也只有作者看得懂，发布版默认不显示。）
