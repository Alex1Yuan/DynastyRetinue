# DynastyRetinue · 家族卫队

[English](README.en.md) · [中英文更新说明](CHANGELOG.md) · [源码构建](BUILDING.md) · [下载](https://www.nexusmods.com/warhammer40kroguetrader/mods/566)

给《Warhammer 40,000: Rogue Trader》加入 **AI 地面卫队、AI 护航舰队和座舰改装**。1.8.5 加入卫队友伤保护与“只加属性”成长选项，并修复部分卫兵冷读档后的属性变化；保留连射卫移动修复、地面留守和护航舰队功能。

用原版单位模板生成卫兵、按原版职业链自动成长、自动发装备，跟着你打完整场战斗。座舰那边可以用废料把护卫舰改装成巡洋舰或大巡洋舰，拿到对应的护盾、装甲、撞角与开火次数加成。

### 友伤与成长选项（1.8.5）

UMM「战斗与行为」中的**卫队友伤保护**默认关闭、按需开启。开启后：正常友方卫兵直接对友方造成的生命伤害会被拦截，跳弹排除非敌方，卫兵施法不触发自动灵能现象与亚空间灾难。关闭这个开关后，这三项恢复原版规则；「卫兵灵能不推高亚空间威胁」仍是独立选项。玩家自己的攻击、敌方伤害及卫兵技能自身耗血保持原规则。保护不承诺覆盖伤害来源已变成环境物体的连锁爆炸，以及非伤害状态效果。联机双方需保持该被动规则设置一致，可用设置核对查看差异。

UMM 面板“成长”提供三种组合：关闭“自动成长”停止后续职业加点；开启时默认完整成长；同时勾选“只加属性”则只增加职业链中的纯属性与装备熟练度。单位自带能力和装备效果保留，已学技能不会删除，跳过的等级也不会在切回完整模式时补发技能。希望使用完整简化方案，请先设置再招募。

部分原版 NPC 底盘的属性修正在区域加载前计算，曾导致冷读档后属性与生命值改变；现在在区域恢复和留守后出战时定向刷新，所有成长模式均适用。已有“健壮体魄”的卫兵也会在属性成长后立即更新生命值加成。没有新增逐帧全场扫描。

### 连射卫兵移动修复（1.8.4）

普通连射兵不再继承原版遭遇中的“固守位置”效果。已有连射兵读取地面存档、进入地面区域或从留守重新出战时会自动修正，无需遣散重招。只去除这条NPC站桩逻辑，其他来源的定身仍然有效，原版敌人与剧情NPC不受影响。修复不增加移动点数、不补充已消耗的移动力，也不新增逐帧扫描。

### 低等级招募修复（1.8.3）

自动成长只会补发卫兵已经达到相应职业等级的天赋，避免1级招募时提前获得后续等级的能力。原版单位自带能力、装备赋予的效果，以及现有装备档位规则保留。

更新不会自动回收旧档中已经获得的特性。如果需要重建受影响的普通卫兵，可在更新后单独遣散并重新招募；新兵不会保留被遣散者的名字、经验和装备实例。无需清空整支卫队。

### 地面卫队留守（1.8.2）

在「卫队管理 → 地面卫队 → 在册」点击单个卫兵的「留守／出战」，或使用底部的「全部留守／全部出战」。留守暂时让卫兵离开场上，保留原来的名字、等级和装备，不需要遣散重招；仍占招募名额和精英名额。

出战安排跟随游戏存档保存，读取旧档会恢复当时的安排；缺少留守记录的旧版本存档默认全员出战。留守卫兵不会被过图、自动传送或卡住救援拉回队伍。战斗中、倒地或无法中断当前动作时不可切换；地面出战在主角附近归队，非地面区域安排出战后会在下次登陆归队。合作模式由房主操作，本轮双端实机验证尚未完成。

## 卸载前：完成清理并存档

**卫兵是持久实体，会写进存档的 `party.json`；改装过的座舰也会。** 它们不是临时召唤物 ——
关掉 mod 不会让它们消失，而是把它们**留在存档里、同时拿走处理它们的代码**。

在**禁用 mod / 卸载 mod / 在 Steam 里关闭 DLC / 更换 Steam 账号**之前：

1. 打开 UMM 面板 → **面板顶部**（「卫队 在册 N」那一行下面）→ 点【**遣散全部**】，确认日志出现「复查在册 0，清理完成」
2. 如果招募过护航舰队：先离开海战，再到「卫队管理 → 护航舰队 → 在册」逐舰遣散。
3. 如果改装过座舰：**舰船** 区 → 点【**还原原版船模**】（或在船坞对话里选「还原原版」）。
4. **保存游戏**，然后再停用 mod。

清理后必须保存游戏；读取清理前的旧档仍会恢复当时的状态。

<summary>不按流程直接卸载会怎样 —— 两条路都实测过，这是结果</summary>

### 先说结论

| | 存档能打开 | 后果 | 能不能修 |
|---|---|---|---|
| **按流程清理后卸载** | ✅ | 无残留 | — |
| **不清理直接卸载** | ✅ **也能打开** | 卫兵变成不可操作的静止 NPC；改装过的座舰在管理界面显示为**一片洋红** | ⚠️ 卸载状态下**没有任何办法**；但装回 mod 就能完全修好 |
| **卸载错了之后补救** | ✅ | **可以完全恢复** | ✅ 装回 mod → 遣散 + 还原 → 存盘 |

**上述测试中的存档均能正常打开。** 避免引入存档依赖是设计目标：本 mod 的身份和配置记录使用裸字符串或原版枚举
（`PartCombatGroup.m_Id`、`PartUnitDescription.CustomName`、`m_CustomPrefabGuid`、`PartUnitState.Size`），
没有任何 mod 自建蓝图进过类型化字段 —— 而"卸载后存档打不开"这个最严重的故障恰恰只由后者引起
（那类字段的反序列化处没有 try/catch，解析不到就整个存档读不出来）。

### 实测一：按流程清理后卸载

遣散 → 还原船模 → 存盘 → 把 mod 文件夹整个移出 → 读档。

结果：正常读取，`Player.log` 零异常。解包存档核对：
`kgd.guard` / `kgd.e:` 计数为 **0**，座舰 `size=Frigate_1x2`、`customPrefab=None`。**零残留。**

### 实测二：故意不清理就卸载

留 1 个卫兵 + 把船改成大巡（换了船模），存盘，把 mod 移出，读档。

结果：**能读进去，无异常**。但是——

- **卫兵**：变成场景里一个静止的 NPC。名字和模型都在，站在原地不动，
  **不在队伍栏里、不能操作、也没有任何办法删掉它**（遣散按钮随 mod 一起消失了）。
- **座舰**：分档还是大巡（两个 Prow 槽位都在，说明原版枚举正常持久化），
  但船体模型在管理界面里渲染成**整片洋红** —— 那是 Unity 的「材质丢失」占位色。
  日志里对应 `Failed to read data for the AssetBundle ''`：
  负责让自定义船模的资源包保持加载的代码随 mod 一起没了。
- **两样都无法在游戏内修复** —— 原版没有任何界面能把船改回护卫舰，也没有办法移除那个卫兵。

### 实测三：卸载错了，还能不能补救

把 mod 装回去，读那个保留未清理状态的存档。

结果：**完全恢复**。

- 那个"站着不动的雕像"不是被强行删掉的 —— mod 认出了它并把它**还原成一个正常卫兵**
  （日志：`区域加载完成，重建 1 名卫兵的运行时状态`），然后正常遣散。
- 座舰的洋红当场消失（日志：`已为换装后的船体补上 BaseRenderer` —— 原版只给玩家那三条船
  接了渲染器，换过船模的船需要 mod 补上），随后正常还原成护卫舰。
- 清理后存盘，解包核对：`kgd.guard` / `kgd.e:` / `kgd.dead` **全部为 0**，
  座舰 `size=Frigate_1x2`、`customPrefab=None` —— 与「按流程卸载」那次的结果**完全等价**。

### 所以

**这些测试覆盖了上述三种卸载路径，不能保证任意存档、DLC 和 mod 组合都安全。** 在测试案例中，不按流程卸载留下的状态可通过装回 mod、清理并重新存档恢复。

两分钟的清理流程能完全避免这一趟。

## 安装

> **从 0.8x 版升级的话，先做这一步**：旧版的文件夹名是 `KgdRetinue`。
> 新版叫 `DynastyRetinue`，**解压新版只会多出一个文件夹，不会覆盖旧的** ——
> UMM 是按「子目录里有没有 `Info.json`」装载的，不认目录名。
> 两份同时跑 = 两套 Harmony 补丁、两个面板、两份名册认领同一批卫兵。
> 所以请把旧的 `KgdRetinue` 文件夹**整个删掉或移出 UnityModManager 目录**，
> 只改名是没用的。（存档里的卫兵不受影响，身份标记跨版本保持不变。）

1. 装 [Unity Mod Manager](https://www.nexusmods.com/site/mods/21) **0.23.0 或更高**，用它安装本 mod
2. 启动游戏，`Ctrl + F10` 打开 UMM 面板，找到 **Dynasty Retinue & Refit**
3. 读一个存档（不在存档里时大部分功能不可用，这是正常的）

`archetypes.json`、`plans.json`、`looks.json`、`l10n_en.json` **四个数据文件应与 DLL 放在一起**。
前两个缺失时 mod 会退回内置默认值并在日志里报错，功能大幅退化；
`l10n_en.json` 缺失是**静默**回落中文 —— 英文玩家的表现是「这 mod 没做英文」，最难自查。

### 关于 DLC

基础功能不强制要求 DLC，但部分单位模板和职业内容依赖 DLC（包括 DLC3：Dark Legacy）。
已配置本体替代模板的分型可回退；没有可用模板或所需职业内容的选项可能不可用。
并非所有分型都有本体替代，尤其不能保证无 DLC 时机械教的全部内容可用；以招募面板的可用性提示为准。
个别精英（圣焰·净罪修女）和一条 T2 职业链（火杖行刑者，DLC1）在缺对应 DLC 时不可用。

## 快速上手

**招募**：从 UMM 面板打开卫队管理，或与舰桥高阶顾问对话，选择「（卫队）关于地面卫队与护航舰队的事宜……」。窗口分为「地面卫队／护航舰队」，舰队页再分「在册／招募」。

**地面卫队招募上限**由**利润因子**决定：默认每 15 点解锁 1 名，最多 6 名（90 点全解锁）。护航舰队使用独立的 PF 占用预算与舰队容量，见下文。

**换船**：跟高阶顾问对话选「（船坞）关于座舰的改装事宜……」，用废料购买：

| 目标 | 费用 |
|---|---|
| 护卫舰 → 巡洋舰 | 500 废料 |
| 护卫舰 → 大巡洋舰 | 1000 废料 |
| 巡洋舰 → 大巡洋舰 | **500**（只补差价） |
| 降级 / 还原 | **退还差价** |

## 功能

### 卫队

- **6 条分型**（近战 / 连射 / 狙击 / 灵能 / 军官 / 机械教）× **3 个阶位**，跟着主角等级解锁
- **14 名精英**；机械教分为教条／异端两条路线，走各自的职业链和装备表
- **自动成长**：每次进区域按当前阶位补齐等级、加点、发装备
- **经验追赶**：等级落后主角越多，获得的经验倍率越高（最低 0.8×，可配置）
- **命名**：`军衔·人名`。晋升只换军衔，人名跟他一辈子；死了这个人就没了
- **死亡规则**：普通卫兵**永久死亡**，精英**倒地可救**
- **士气隔离**：卫兵受伤/倒地不扣你的队伍士气；可选独立士气池
- **镜头**：卫兵行动时可以不跟随，省掉大量等待

### 外观

卫兵的外观可以和数值、装备**完全分开**：数值来自单位蓝图，天赋职业来自我们的配表，
外观则由 UMM 面板「外观」区里的一张矩阵决定。

```
风格  [跟随装备] [卡斯金] [克里格]              [全部设为]
        T1↓    T2↓    T3↓   精英↓     ← 点列头刷整列
 近战→  跟随   卡斯金 卡斯金  跟随       ← 点行头刷整行
 狙击→  ...
```

先选一个风格当"画笔"，再点格子刷。三列 T1/T2/T3 不是并存的三种卫兵，而是
**随主角等级推进，这个分型的外观依次变成什么**。第四列是精英，不随阶位变。

- **跟随装备**（默认）= 原版行为，模型随身上的装备变化
- 底下「显示所穿装备的外观」关掉之后，只显示选定的风格；**手持武器不受影响**
- 外观偏好保留在各人的本地设置中；合作招募与恢复会同步本次操作所需的外观值，操作结束后还原本地设置。

**风格清单来自 `looks.json`，可以自己改、自己加。** 两种做法：

```jsonc
{ "looks": [
  // ① 拼部件：用捏脸系统的 EquipmentEntity 组装。脸会从原版预设角色里按性别挑，
  //    所以每个卫兵长相不同；缺点是要自己挑件、可能穿模。
  { "id": "kasrkin", "name": "卡斯金", "name_en": "Kasrkin",
    "parts": ["394e4b94...", "a777e0db..."] },

  // ② 借模型：直接用某个原版单位的整体模型。零穿模风险、自动统一，
  //    但每个卫兵长得一模一样，而且「显示所穿装备」对它无效（烘焙模型本来就不吃装备视觉）。
  { "id": "krieg", "name": "克里格", "name_en": "Death Korps of Krieg",
    "unit": "89c64997...",
    // 借模型时还能按分型指定不同单位 —— 键是 archetypes.json 里的 name
    "unitByArchetype": { "狙击": "396ab842...", "军官": "6d16a5ba..." } }
] }
```

改完点界面上的【**重载风格**】即可生效，**不用重启游戏**。

`unit` 和 `parts` 二选一，`unit` 优先；两者都没有的条目会被跳过并记一条日志。
`parts` 里填的是 **KingmakerEquipmentEntity 蓝图 guid**，`unit` 里是 **BlueprintUnit guid**，
全部是 vanilla 资源 —— **mod 不发明任何 AssetId**。

**改坏了不会出事**，每一种情况都有明确回落，且都会记一行日志：

| 情况 | 结果 |
|---|---|
| `parts` 里某个 guid 解析不到 | 跳过这一件，其余照常 |
| `unit` 解析不到（比如缺 DLC3） | 这套风格回落成「跟随装备」 |
| 条目既没有 `unit` 也没有 `parts` | 整条跳过 |
| 矩阵里点名了一个已删除的 id | 该格按「跟随装备」处理 |

外观是**纯表现层**：不写进存档、不进联机同步哈希。删掉 mod 或把矩阵设回「跟随装备」，
下次生成视图就自动恢复原样，不需要任何清理动作。

### 舰船

- 分档加成：护盾扇区上限、各面装甲、撞角距离、每回合开火次数
- 换船模（目前**只有帝国 Gothic 级巡洋舰和 Dictator 级大巡洋舰经过校准**，其余船体在船坞里会标注「未调整好」并禁止购买）
- 自动补齐缺失的武器挂点，修复原版「光矛在虚空里开火」的问题

### 护航舰队（1.8.1）

在「卫队管理 → 护航舰队」招募 AI 僚舰。每艘舰可独立改名、遣散和逐槽换装；巡洋舰与大巡洋舰还可在当前舰型上限内增加开火次数／射程。每舰装备区默认收起，点击「展开装备」后选择武器或组件。船坞继续只管理玩家座舰。

招募时先选「护卫舰／巡洋舰／大巡洋舰」，再选具体型号。选型只更新预览；点击「招募所选舰型」才会招募并占用PF。详情展示完整船模、各炮位武器、四类主组件和原生附带能力，可用右侧滚动条查看完整清单。预览是按型号缓存的静态图，关闭窗口后释放，不持续运行预览相机。

| 舰型 | 原版武器布局 | 容量 | 默认舰体占用 |
| --- | --- | --- | --- |
| 剑级护卫舰 | 左右舷各一门宏炮 | 1 | 10 PF |
| 舰首光矛护卫舰 | 船脊宏炮、舰首光矛 | 1 | 10 PF |
| Gothic 级巡洋舰 | 四门舷炮、舰首光矛 | 2 | 20 PF |
| 海盗 Dictator 级巡洋舰 | 四门舷侧宏炮、两门舷侧光矛；原生载机 | 2 | 20 PF |
| Universe 级大巡洋舰 | 两门船脊光矛、左右舷宏炮 | 3 | 30 PF |
| 混沌战列巡洋舰 | 船脊光矛、四门舷侧宏炮；原生载机 | 3 | 30 PF |

两种护卫使用原版相同的 Sword 船模，武器布局不同。各型号沿用自身原装装备与AI；海盗 Dictator 还保留原版低血量撤退行为。原生载机随母舰型号保留，暂不开放载机换装。

舰队容量上限为6。PF显示为「已占／上限」，只占用预算，不扣除原版利润因子；地面卫队名额独立计算。每个偏离原装的开放槽默认占2 PF，每门受影响舰炮每增加一次开火占2 PF、每增加一格射程占1 PF。界面显示影响炮数和费用公式。PF下降或调高费率造成超预算时，已有舰队仍可出战，遣散、恢复原装、降低强化和同价替换仍允许。

换装支持经过AI验证的普通舰炮，以及等离子驱动器、虚空盾发生器、探测阵列、装甲板四类主组件。候选需要适配真实槽位并已记录获得；载入时会补录当前库存和座舰装备。换装不消耗或移动真实物品，恢复原装始终可选。鱼雷、舰载机与隐藏槽不在本次换装范围。

舰队名册、名字、装配、强化和已获得舰装记录**随游戏存档保存**。同一战役的不同存档也各自独立；修改后需保存游戏，读取旧档会恢复当时的舰队。开关与PF费率等偏好仍在mod设置中。

护航舰按原版AI航线行动。击杀后会尝试用剩余炮次攻击其他合法目标；当前地点无目标时，可沿已有后续航点移动再开火。合作模式由房主编辑和发起舰队事务，战斗执行使用房主确定的配置。

## 已知限制

- **座舰换模只有两条船体校准过**。座舰目录里其余船体（混沌、灵族、运输舰）可以在 UMM 面板里强行切换用于尝试，但挂点位置和缩放没有验证过。船坞窗口不会卖给玩家；此限制与护航舰队的原生舰型选择独立。
- 护航舰型的完整预览、母舰开火、载机发射和本场战斗结算已做单机验证。载机自主开火、返航、战中冷读档、最终清理及部分舰型炮口视觉位置仍待进一步测试；本轮未完成双端联机实测。
- 测试日志仍记录到区域伤害规则与战后语音异常，本场奖励界面正常打开。这些异常继续排查，尚未确认来源，也不表示所有海战结算问题均已解决。
- **同一挂点只能显示一件武器美术**。这是原版行为（`StarshipView` 是先毁后建），两件要求同一槽位的武器只有一件可见。本 mod 会优先保留光矛。
- **部分武器没有炮塔美术**（鱼雷发射管等），这是原版数据如此，不是缺陷。
- 精英模板中有一个来自 **DLC3**，没有该 DLC 时那名精英不可用。
- 【改装备】按钮属于第二阶段功能，目前点击只会提示"尚未实现"，卫兵使用固定装备组。

## 出问题时

日志在 `%USERPROFILE%\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\UnityModManager\DynastyRetinue\dynasty_log.txt`。

反馈时请带上这个文件 —— 里面记录了每一步的判据和数值，绝大多数问题能直接从日志定位，不需要来回猜。

**最省事的反馈方式**：UMM 面板上点【**导出诊断包**】。它会把版本、你改过的设置、在册卫兵、舰船状态和日志尾部打包成**一个文件**，并且**已经把用户名抹成 `<USER>`**。比直接发完整日志小得多，信息也全得多 —— 完整日志通常有好几 MB，多数地方传不上去。

（面板上没有「开发 · 测试」区是正常的：那些按钮会清空卫兵、输出也只有作者看得懂，发布版默认不显示。）
